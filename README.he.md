# Streamlate

**עברית** · [English](README.md) · [Português](README.pt-BR.md) · [Español](README.es.md) · [Polski](README.pl.md) · [日本語](README.ja.md) · [中文](README.zh.md) · [한국어](README.ko.md)

תרגום חי, חינמי ומקומי לסטרימרים.

- **הקול שלכם ← כתוביות בשפה אחרת, ישירות בשידור.** בכל כיוון: דברו עברית
  וקבלו כתוביות באנגלית כדי שהעולם יבין אתכם, או דברו אנגלית וקבלו כתוביות
  בעברית — הכתוביות מופיעות בתוך OBS כשתי שניות אחרי הדיבור. אותה שפה בשני
  הצדדים = כתוביות רגילות (נגישות).
- **הצ'אט שלהם ← השפה שלכם, בשבילכם.** כל הודעה בשפה זרה מתורגמת בשכבה
  שקופה בתוך המשחק ובדף שנפתח בנייד. עובד עם צ'אט של **Twitch, YouTube
  ו-Kick** — פשוט הזינו שם ערוץ, ‎@handle או כתובת kick.com.
- **בלי חשבונות, בלי מפתחות API, בלי ענן חובה.** הכול רץ על המחשב שלכם.
  קריאת הצ'אט אנונימית — לא נוגעת בחשבון שלכם.

## איך זה מתאים את עצמו למחשב שלכם (אוטומטית)

בהרצה הראשונה התוכנה בודקת את כרטיס המסך ובוחרת את מודל התרגום הגדול
ביותר שנכנס — אתם לא בוחרים כלום:

| כרטיס המסך | המנוע שנבחר | איכות |
|---|---|---|
| ‎20GB+‎ (4090/5090…) | Qwen 27B מקומי | הטובה ביותר |
| ‎11–20GB | Gemma 12B מקומי | מצוינת |
| ‎6–11GB | Gemma 4B מקומי | טובה |
| פחות / ללא | מנוע Google חינמי | סבירה — ואפס שימוש ב-GPU |

זיהוי הדיבור (Whisper) רץ על ה-GPU כשיש, אחרת על המעבד. לדוברי עברית
התוכנה עוברת אוטומטית למודל שמיעה חזק יותר (medium).

## התקנה (Windows) — קובץ אחד עושה הכול

1. הורידו את התיקייה (כפתור ירוק **Code ← Download ZIP**, חלצו לאן שנוח).
2. לחיצה כפולה על **`install.bat`** פעם אחת. הוא מתקין לבד את Python ואת
   מנוע ה-AI ‏Ollama אם אין לכם (שקט, בלי מסכי התקנה), יוצר את האייקונים
   בשולחן העבודה ופותח את אשף ההגדרה — הערוץ, השפה, המיקרופון, סיימתם.

## שימוש

- **`Streamlate`** (אייקון סגול): מדליק הכול — שכבת הצ'אט, דף הנייד, מנוע
  הכתוביות.
- ב-OBS, פעם אחת: `Sources ← + ← Browser`, כתובת `http://localhost:8788`,
  רוחב `1400`, גובה `300`. זה יוצר רצועה קטנה — **גררו אותה לאן שרוצים כמו
  כל מקור**; הכתוביות נצמדות לתחתית שלה.
- נייד: פתחו את הכתובת שמופיעה באייקון שבמגש (אותו Wi-Fi), או סרקו את
  `phone_qr.png`.
- **`Streamlate OFF`** (אייקון אפור): מכבה הכול.

## התאמה אישית

קליק ימני על האייקון הסגול ← **Change background image…** לבחירת כל תמונה
(רקע אנימה, לוגו…) — השכבה ודף הנייד ישתמשו בה, מוכהה אוטומטית כדי שהצ'אט
יישאר קריא. **מצב הזזה** במגש משחרר את השכבה לגרירה חופשית; לחיצה נוספת
נועלת חזרה למצב משחק (קליקים עוברים דרכה).

## הערות

- דף הנייד עובד ברשת ה-Wi-Fi הביתית.
- אם Ollama כבוי — התרגום עובר אוטומטית ל-Google, שום דבר לא נשבר.
- רישיון MIT — תעשו מה שבא לכם.

## מצב צופה — צפו בסטרימרים זרים

Streamlate עובד גם בכיוון ההפוך. פתחו את **Streamlate Control** ←
**👁 מצב צופה**: במקום לתרגם את השידור שלכם לצופים, הוא מתרגם שידור
שאתם צופים בו.

- **כתוביות קול חיות** — הפעילו כל שידור; שפת הסטרימר מזוהה אוטומטית
  ומתורגמת לשפה שלכם בגלולת כתוביות שניתן לגרור (קליק ימני: שפה, גודל,
  טקסט מקורי, מקור שמע).
- **טקסט מהמסך (בטא)** — קליק ימני ← *תרגום טקסט מהמסך*, גררו מסגרת סביב
  הצ'אט או הטקסט שלהם ופאנל תרגום חי יופיע לצידו. ליפנית/קוריאנית/סינית
  הוסיפו את השפה בהגדרות Windows ← שפה.

מגבלה כנה: השמע של השידור מגיע מעורבב — אי אפשר לבודד רק את המיקרופון של
הסטרימר, ומוזיקה עם שירה עלולה ליצור שורות מיותרות. אם המוזיקה היא שלכם,
נגנו אותה בהתקן פלט אחר ובחרו את התקן השידור תחת *מקור שמע*.
**🎥 חזרה למצב סטרימר** באותו פאנל מחזיר הכול.

### קישור קול — הדיבור שלך בשפה של כל חבר

מגש (סגול) ← **🎤 קישור קול**: מעתיק דף ציבורי שבו כל אחד — בלי להתקין
כלום — קורא את מה שאתה אומר מתורגם בזמן אמת לשפה שהוא בוחר (30 שפות).
מוזן מתמלול המיקרופון שלך בלבד: בלי סאונד מהמשחק, בלי מוזיקה, בלי קולות
אחרים. משתמש במנהרת ה-QR לצופים כשהיא פעילה.
